Clock timer test

This checks whether Recipes can hand a timer to the iPhone’s Clock app, so it rings even when the phone is locked. It needs a small Shortcut that you make once.

1. Make the Shortcut

  1. Open the Shortcuts app and tap + to start a new shortcut.
  2. Tap its name at the top, choose Rename, and call it exactly Recipe Timer.
  3. Search the actions for Start Timer and add it.
  4. In that action, tap the number. From the row above the keyboard, choose Shortcut Input. Leave the unit on minutes.
  5. Tap Done.

2. Try it

Open this page from the Recipes icon on your Home Screen (Settings, then Try the Clock timer). Opening it in Safari tests the wrong thing.

Start a 1 minute timer Start one, then try to come back here

3. What to tell me

  • Did a 1 minute timer appear in Clock, and did it ring?
  • How did you get back to Recipes: an arrow at the top left of the screen, on its own, or only by swiping?
  • With the second button, did it return here, open Safari, or do nothing?
  • Did it still ring with the phone locked?

If any step looks different on your phone, say what you see instead. The names of things in Shortcuts change between iOS versions.
